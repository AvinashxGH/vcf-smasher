# 🧬 VCF Smasher

## Overview
A Python-based ETL (Extract, Transform, Load) pipeline designed to parse, clean, and analyze heavy genomic datasets (ClinVar VCF files).

## Features
* **Data Extraction:** Parses complex VCF formats to extract critical genetic information.
* **Transformation:** Cleans and filters pathogenic mutations programmatically.
* **Optimization:** Designed to handle extremely large datasets efficiently without crashing memory.

## Tech Stack
* Python 🐍
* Pandas 🐼
* Bioinformatics Data Parsing 💻
